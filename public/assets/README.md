# Assets Directory

This directory contains static assets for the Spacesio Beryl application.

## Structure

- `/images`: General UI images, background photos.
- `/products`: High-quality product photography.
- `/projects`: Gallery images for architectural projects.
- `/textures`: Texture maps (albedo, normal, roughness, etc.) for 3D materials.
- `/models`: 3D models (GLTF, GLB).
- `/hdri`: Environment maps for 3D lighting.
- `/icons`: Custom SVG icons.

**Important:** Heavy assets should be lazy-loaded or optimized before being placed here.
